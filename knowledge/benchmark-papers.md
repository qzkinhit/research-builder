# benchmark 类论文的叙事

方法论文用 `paper-anatomy.md` 的骨架。纯 benchmark 论文的贡献是数据集、协议和评测视角，组织方式不同，按本文件写。

**范本。** TIME (It's TIME: Towards the Next Generation of Time Series Forecasting Benchmarks, arXiv:2602.12147)，通篇没有定理。用调研工具抓它的 LaTeX 源与 HTML 对照阅读。

```bash
bash paper-survey/tools/fetch_arxiv.sh 2602.12147 researched_papers
```

## 七条做法

1. **贡献收成两个维度。** 开篇把贡献归为两个基本维度，例如「基准构建」与「评测视角」。自己的论文对应成「统一的任务框架」与「跨设置的评测视角」这一类。
2. **引言用「现有基准的 N 个缺陷」切入。** 范本列了四个缺陷(陈旧的数据、数据完整性、任务设定、分析视角)。自己的论文列出现有基准在任务覆盖、可比性、噪声可控性和指标定义上的缺陷，每个缺陷对应一项设计。
3. **贡献靠工件。** 数据集、协议、排行榜和新的评测视角是贡献，不需要定理。
4. **严谨落在协议与设计校验上。** 范本用 Fisher Score 和 Cohen's d 验证特征分组的判别力，用 Mann-Whitney U 检验给出统计显著性。自己的论文对应校验注入噪声的可控性、等预算的公平性和 baseline 矩阵的覆盖度。
5. **发现是观察，不是证明。** 范本报告「排名随聚合粒度变化」「模型在平稳性上的表现翻转」。自己的论文报告跨设置的排名翻转、没有单一方法处处最优这类观察性发现。
6. **多粒度排行榜加定性可视化。** 排行榜按数据集、任务类别和全局三个粒度给出，再用可视化补充定量结果。
7. **不放方法论文式的最优性定理。** benchmark 论文里的精细定理显得错位。有用的定理放进对应的方法论文。

## 结构

| 节 | 内容 |
|---|---|
| 引言 | 现有基准的缺陷 → 本基准的两维贡献 → 主要发现 |
| 相关工作 | 现有基准逐个对比，末尾一张覆盖度表 |
| 基准构建 | 数据来源、任务定义、噪声或扰动的生成、划分与防泄漏 |
| 评测协议 | 指标、等预算规则、baseline 矩阵、统计检验 |
| 设计校验 | 协议各项设计的判别力与公平性检验 |
| 结果与发现 | 多粒度排行榜，编号的观察性发现 |
| 结论 | 基准的用法、维护计划与局限 |
