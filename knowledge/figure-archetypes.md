# 图的版式原型

本文件描述动机图、系统图和本子图的版式原型，从作者若干篇已发表或在投论文的插图与基金本子插图中归纳而来。画图的操作规则(箭头、字号、矢量、对象组合、检查)在 `../paper-figure-pptx/SKILL.md`，实验数据图在 `../figure-style/`。本文件只管画什么、怎么排。

用户在 `../materials/figures/` 放了自己的参考图时，以参考图为准，本文件作为没有参考图时的默认版式。

## 1. 动机图

动机图让读者先看到具体输入、现有的几种选择和它们的差异，再引出要解决的问题。颜色区分数据状态、动作或对比策略。

**原型 A，三段式。** 双栏宽。

| 区域 | 内容 |
|---|---|
| 左 | 动作与预算的图解，即方法可选的几种动作，每种动作的代价，以及两阶段决策的流程 |
| 中 | 策略空间。以两个关键性质为横纵轴，撒点表示大量随机策略，颜色编码下游效果与代价，标出几种极端策略和本文方法的落点 |
| 右 | 同一个例子在各策略下的结果，例如几种策略下的数据分布与决策边界，每个小面板标注两个性质的取值和下游效果 |

适用于「若干种动作之间存在取舍」的问题。引言的 Example 环境逐个解释这几个面板。

**原型 B，左过程右证据。**

| 区域 | 内容 |
|---|---|
| 左 | 用表格、模型和动作图标表达准备或处理过程 |
| 右 | 策略空间加一张少量数字的证据表，说明为什么现有做法不够 |
| 底 | 一条横向连接，表示数据与模型之间的反馈 |

适用于「数据处理与模型训练交替进行」的问题。

**原型 C，具体实例。** 单栏宽。用一条具体的约束、几条记录和一段外部知识，展示不同处理器在同一实例上的输出。适用于需要说明「不同方法看到的证据不同」的问题。

**原型 D，时序效应。** 单栏宽。左面板画带故障的运行与配对的无故障运行，注入时刻用竖直虚线，两条曲线之间涂浅红并标注效应。右面板用堆叠条形图展示各变量的原因构成。绘图代码在 `../figure-style/examples/ex_c_motivation.py`。

## 2. 系统图

系统图对应方法的输入、状态、操作、条件和输出。

**原型 E，三阶段横排加贯穿例子。** 双栏宽，最常用。

- 三个阶段从左到右排开，每个阶段一个功能色(例如蓝、橙、绿)，阶段标题用深色底白字。
- 上半部分画方法，即每个阶段的组件和它们之间的数据流。
- 下半部分画同一个例子在三个阶段中的变化，例子与上方的组件纵向对齐。
- 跨轮反馈画在底部，用一条细折线从最后阶段回到第一阶段，标注反馈的内容。
- 表格例子直接嵌在操作旁边，读者能看出这一步把哪几行改成了什么。

**原型 F，阶段容器加主流程箭头。**

- 每个阶段一个浅色容器，深蓝标题。
- 主流程用红色粗箭头贯穿各容器，辅助数据流用细箭头。
- 右侧可加一个公式面板，列出各阶段的形式化记号。

**原型 G，双分支汇聚。** 左侧数据源分出上下两条并行分支，分别评估两个正交的维度，右侧加权融合成一个输出。适用于方法由两个独立维度组成的情况。

阶段数按实际方法定，三阶段只是最常见的情况。方法里实际存在的条件(必选候选、可选分支、参照集、跨轮更新)都要画出来，简图不能显得比方法的保证更强。

## 3. 本子图

**研究内容关系图。** 三个研究点自下而上或从左到右排列，标出依赖关系，例如研究点一的度量结果供研究点二初筛，研究点三把前两者的算子编排成流程。顶部写总目标，底部写应用场景。

**研究内容小图。** 每个研究点一张，分上下两半。

| 区域 | 内容 |
|---|---|
| 上半，问题与挑战 | 两到三条挑战，每条一个标题加一句说明，配能直观表达问题的图标组合，例如不同模态的图标之间画断开的连线或红色叉号 |
| 下半，拟解决方案 | 与挑战一一对应的子点，每个子点写方法名和两三个关键技术 |

**技术路线图。** 每个研究点一张。左侧是输入数据，中间按子点分成纵向的几栏，每栏从上到下是技术步骤，右侧是输出和验证。关键公式放在右侧的公式框里。

**成果概览图。** 人才项目用。中心写研究方向，周围按创新维度分块，每块放代表性成果的系统图缩略和一句话效果。

## 4. 六种通用布局

没有参考图时，从下表选最接近的布局。

| 布局 | 结构 | 适合 |
|---|---|---|
| 总体技术路线 | 上下两条横向流水线，右侧评估区，右上反馈环 | 整个研究的总图，模块多、关系密 |
| 四阶段流水线加下挂细节 | 顶部四个阶段横向箭头，每个阶段向下展开细节框，右侧公式框 | 四个顺序阶段且每阶段要展开的方法 |
| 四阶段流水线加诊断子项 | 同上，最后一阶段列出可解释或诊断子项 | 以解释或诊断收尾的流程 |
| 双分支汇聚 | 见原型 G | 两个正交维度合并的系统 |
| 贡献页 | 左上创新点，左下系统小图，右侧结果表，底部一句红色结论 | 汇报中展示一个贡献 |
| 论文级系统流程 | 三段虚线分区，各区写组件名，右侧橙色公式面板 | 论文的核心方法图 |

## 5. 图标语义

图标只在能说明数据、模型、操作或结果时使用。同一张图里同一个概念始终用同一个图标。

| 图标样貌 | 表示 |
|---|---|
| 圆柱数据库，可叠加表格或网页小图 | 数据集、数据源、数据池 |
| 圆柱加橙色警告三角 | 数据质量问题，如缺失、异常、重复、错误值 |
| 盾牌加数据 | 质量保障、真实性 |
| 放大镜加信号 | 检测、分析 |
| 齿轮 | 模型、处理流程、指标聚合 |
| 仪表盘加柱状 | 评估、优化校验 |
| 饼图加柱状加勾选 | 质量维度刻画、统计分析 |
| 脑加网络节点 | 模型反馈、关联建模 |
| 灯泡 | 创新点、可解释 |
| 钻石 | 高价值数据 |
| 文档加勾或笔 | 报告、规则、标注 |
| 树状三框 | 层级结构、模型需求 |
| 流程文件加节点 | 修复策略集、流程编排 |
| 机械臂或传感器 | 原始工业数据、采集 |

`../paper-figure-pptx/assets/icon-library/starter/` 有一组按上表含义自绘的入门 SVG 图标，用户自己的图标库放 `../materials/icons/` 后用 `../paper-figure-pptx/scripts/extract_icon_library.py` 提取。

## 6. 配色与字号

- 功能色每个阶段一种，同一阶段内保持一致。本文方法与关键结论用红色。
- 字号只设三到四个层级(标题、模块标题、正文、注释)。纸面字号按 `PPT 字号 × 论文中图宽 ÷ PPT 画布宽` 换算，正文不低于 6 pt。
- 「更学术」指信息清楚，不指多加灰色、阴影、卡片或抽象图标。
