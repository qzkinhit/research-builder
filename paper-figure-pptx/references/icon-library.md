# 矢量图标库与设计

添加、提取、选择或自行设计图标时读本文件。先按当前流程的含义选图标，再检查风格和占用的空间。

## 已保存的素材

素材在技能内的 `assets/icon-library/` 下，每个来源一个子目录，跨项目直接复用，不依赖原项目或临时目录。

| 子目录 | 内容 |
|---|---|
| `starter/` | 随技能发布的 16 个自绘入门图标，含 SVG、PNG 回退、[总览](../assets/icon-library/starter/contact-sheet.png) 和 [清单](../assets/icon-library/starter/manifest.json)。设计源是 `scripts/make_starter_icons.py`，改图标就改脚本再重新生成 |
| `<用户来源名>/` | 用户从自己的素材 PPT 提取的图标，用 `scripts/extract_icon_library.py` 生成，见下文「提取与长期复用」 |

- 入门图标的含义与 `knowledge/figure-archetypes.md` 的图标语义表一致，包括数据库、质量问题、质量保障、检测、模型、评估、统计、关联建模、创新点、高价值数据、报告、层级、流程编排、传感采集、表格和基础模型。
- 用户提取的素材库带筛选记录(`selection.json`)。用户否定过的图标只把 ID 留在筛选记录里，用来避免重新导入。
- 候选图标不必全用，也不代表都已被认可。某个素材以前用过只说明使用历史，它的尺寸和布局仍需在新图里确认。

选图标时先看总览，再用清单里的语义标签、SVG ID 和来源核对对象。外观相近而含义不对的图标不用来填空。

## 按现有风格自行设计

素材库表达不准对象、动作或输出时可以自行设计，不必把每个概念都套进现有图标。

- 以当前图里已认可的图标为参照，匹配配色、描边粗细、端点与圆角、轮廓比例和内部细节密度。当前图的字体与功能色保留。
- 优先直接画 SVG 路径，或用可编辑的 PPT 原生形状组。原生组也存一份真正的 SVG 供其他项目复用。暂时导不出真实矢量时，保留可编辑的设计源并如实说明。截图改后缀不算 SVG。
- 带文字的科学标签放在独立的原生文本框里，这样字号还能继续改。
- 新图标与现有图标放在同一尺寸、同一背景下并排检查。按可见轮廓统一视觉大小，透明画布的边缘不计入。保持纵横比，检查细线、色块、留白和小尺寸下的辨认度。
- 新图标放进已有的有效空间，不为它另起一行。

**归档。** 新设计存到 `assets/icon-library/custom/<稳定语义名>/`，包括 SVG、PNG 回退、可编辑设计源或生成脚本，以及一份 `manifest.json`。清单里写用途、作者类型(自行设计)、样式参考、来源素材或父变体 ID、相对文件路径和文件哈希。

- 技能从仓库安装时，归档写进仓库的 `paper-figure-pptx/assets/`，再运行安装或同步脚本。只改 `~/.codex/skills` 或 `~/.claude/skills` 的安装副本，下次同步会被覆盖。
- 没有可写的技能源仓库时，先完整存到当前项目的 `editable/assets/`，并在交付说明里注明还没存回共享库。
- 自行设计的图标不标成来自用户 PPT。改色、裁剪或组合得到的变体另存，不覆盖提取的原件。

## 提取与长期复用

新的素材 PPT 用 `scripts/extract_icon_library.py` 提取，先运行 `--help` 看参数。

```sh
python3 scripts/extract_icon_library.py SOURCE.pptx NEW_OUTPUT_DIR --selection choices.json --columns 6
```

- 提取以图片关系和 SVG 扩展为依据，不按 `imageN` 的文件号去猜 PNG 与 SVG 的配对。
- 输出目录必须是新路径，脚本不覆盖已有素材库。
- 筛选配置与提取脚本分开。每个来源用自己的筛选配置，当前来源的排除清单不套用到别的 PPT。
- 同一个 SVG 在 PPT 的不同对象里可能对应不同的 PNG 回退。索引按关系保留这些回退，所以回退文件数可以多于 SVG 数。
- 保留 SVG 的原始字节和对应的 PNG 回退，记录源文件名与哈希、包内成员路径、实际页码、对象 ID 与名称。索引里不写个人机器的绝对路径。
- 原生形状组、EMF 这类对象不在这个脚本的处理范围内，按 [原生对象、SVG 与合并](pptx-native.md) 另行处理。

从技能库取用素材时，把实际用到的 SVG、回退和来源记录复制到目标图的 `editable/assets/` 或用户指定的目录，构建脚本用项目内的相对路径，最终图不依赖个人技能目录或临时缓存。用户只允许在当前项目保存时按其要求办。

PPT 里已有的完整 SVG 保持为单个图片对象并带 PNG 回退，自绘的原生组保持命名分组。能移动和缩放一个 SVG 对象，不代表能在 PPT 里改它内部的路径或文字。素材文件是 SVG、PPT 里带 SVG 扩展、最终 PDF 保持矢量，这是三项独立的检查，要分别做。
