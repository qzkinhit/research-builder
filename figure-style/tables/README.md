# 实验表的逻辑与样式

本目录给出实验表的写法和可直接复制的 LaTeX 模板，样式取自作者的多篇稿件，它们用同一套配色与版式。`preview.png` 是三张样例表的渲染效果，表中的方法、数据集和数值都是虚构的演示数据。

## 三张表各管什么

实验相关的表只有三张，次要结果一律改成图，因为表占版面而信息密度低。

| 表 | 位置 | 回答的问题 |
|---|---|---|
| 表 1 能力表 | 相关工作末尾 | 每个对比方法属于哪一族，具备哪些能力，本文方法补上了哪些能力 |
| 表 2 数据集表 | 实验章 Setup 的 Datasets 段 | 用了哪些数据集，各属于哪类任务，错误从哪来，规模多大，报告什么指标 |
| 表 3 主表 | 实验章 Findings and Results | 所有方法在所有数据集上的结果，以及按各列名次得到的总排名 |

## 分类逻辑

方法族按方法输出什么、利用什么信息来划分，划分要让能力表的列把族与族、族与本文方法区分开。例如样例把重复记录检测的方法分成基于规则(人工写匹配规则)、基于学习(用标注对训练分类器)、深度匹配(学习记录表示后比较)和基于大模型(提示大模型判断)四族，能力列是是否利用标注预算、是否处理多种错误类型、是否以下游任务为目标、是否解释决策、能否跨数据集迁移、是否带保证。

- 相关工作每段以加粗的族名开头，介绍代表方法和它缺少的能力，缩写在首次出现处加粗定义。
- 表 1 的族列用这些族的缩写，表 3 的行分组用同样的全称和同样的顺序，正文里统计族数的句子与之一致。三处任何一处改了，另外两处一起改。
- 表 1 里的每个方法都在实验中出现，实验章引用表 1，不再逐个介绍 baseline。

## 表 1 能力表

- 第一列是方法名，同族的几个方法可以合成一行并带引用。这一列右对齐，后面加一条竖线。
- 第二列是族的缩写，后面加一条竖线。其余能力列居中，用 ✓ 和 ✗ 标记。
- 能力列选能把本文方法区分出来的性质，例如是否利用标注预算、是否处理多种错误类型、是否以下游任务为目标。列名用缩写，全称在相关工作首段给出。
- 本文方法放在最后一行，前面加一条 `\midrule`，整行浅色底，族列留空，能力全为 ✓。
- 单栏宽，`\footnotesize`，`\tabcolsep` 约 2.2 pt，外面套 `adjustbox` 限制在栏宽以内。

## 表 2 数据集表

- 列为数据集、任务、错误类型、规模和指标，规模属性按领域选，例如记录数与候选对数、传感器数与窗口数。
- 数据集列写加粗的缩写和文献引用，右对齐，后面加一条竖线。其余列居中。
- 任务列取主表列组的缩写。指标列与主表中该数据集所在列的指标一致，一个数据集在主表占两列时两项都写。
- 只列正文实际用到的数据集，行序与主表的列序一致。由已有数据集派生的实验设置不进这张表。
- 错误类型用缩写，例如 T/M/F/D 表示拼写、缺失、格式和重复错误，缩写在 Datasets 段定义一次。
- 规模注明计的是什么，例如记录数或候选对数。全称在正文首次出现处给出，表里只用缩写，每行只占一行。

## 表 3 主表

- 第一列是排名(Rank)，第二列是方法(Method)，两列都右对齐，后面加一条竖线。结果列居中，列组之间加竖线。
- 表头有两行。第一行左上角写 Task / Dataset，其余是任务列组，写成「全称(加粗缩写)」。第二行是 Rank、Method 和数据集名加方向箭头，越大越好用 ↑。指标名不进表头，在数据集表和 Metrics 段给出。
- 行按方法族分组，组行是粗斜体的族全称(`\grp`)，族的顺序与表 1 相同。本文方法放在最后一行，前面加一条 `\midrule`，整行浅色底(`\oursrow`)。
- 每列第一名用深色底加粗(`\best`)，第二名用浅色底(`\secondbest`)，并列的共用同一种底色。第一名、第二名和排名都按表中显示的数值判定，审稿人能用表内数字复算。
- 排名取各列名次的平均，并列的取平均名次，再按平均名次排序，平均名次相同时按显示值的均值排序。
- 没有空格子，也没有横杠。某个 baseline 在某个数据集上不能直接跑时，用简单预处理适配后照跑，数值低也填。
- 保留三位小数。表头与单元格都不换行。`\tabcolsep` 约 3.6 pt，`\arraystretch` 为 0.9。表宽不超过版心，编译后量一下最右列有没有伸进右边距。
- 题注写在什么条件下比较了什么，例如每种方法都拿到相同的标注预算、只有本文方法按下游反馈分配它时的结果，不重复列名。
- 主表的行只由回填脚本写入，不手改数字。新论文可以用 `shade_and_rank.py` 从结果 CSV 生成表体。

## 通用样式

- 横线只用 booktabs 的 `\toprule`、`\midrule`、`\bottomrule`，再加本文方法前的一条 `\midrule`，不加其他横线。
- 竖线只放在名称列之后和列组之间。
- 名称列右对齐，其余列居中。
- 正文中的表用 `\footnotesize`。
- 配色只有三种，`tabBest` 按 35% 浓度作第一名的深底，`tabSecond` 作第二名的浅底，`tabBand` 作本文方法整行的底色。
- 待回填的格子用 `\pend` 红色预填，交稿前全部清零。

## 文件

| 文件 | 用途 |
|---|---|
| `table_macros.tex` | 配色与宏，在论文导言区 `\input{table_macros}` |
| `examples.tex` | 三张样例表，`pdflatex examples.tex` 编译 |
| `examples_main.csv` | 主表样例的演示数据 |
| `shade_and_rank.py` | 从结果 CSV 生成主表表体，含排名、族分组、前两名底色和本文方法行 |
| `examples_mainrows.tex` | `python shade_and_rank.py examples_main.csv --name-macro '\textbf{\sys}'` 的输出 |
| `preview.png` | 样例表的渲染效果 |

生成的表体放进 `tabular` 时，行首的 `\multicolumn` 要求用 TeX 原语读入文件，所以样例在导言区写 `\makeatletter\let\inputrows\@@input\makeatother`，表内写 `\inputrows rows.tex`。也可以由回填脚本把表体直接写进稿件里带标记的块，见 `templates/backfill/`。
