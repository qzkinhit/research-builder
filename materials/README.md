# materials · 你自己的素材

本目录放你自己的论文、本子、声音样本、参考图、图标和演示范例。skill 写作、画图和做 PPT 时引用这里的素材，素材里查不到的内容先问你。目录里除各级 README 外的文件默认不进 git(见仓库根的 `.gitignore`)，你的素材只留在本机。

没有素材时，skill 按 `knowledge/` 的通用骨架写，术语先与你确认。素材越全，写出来越像你。

| 子目录 | 放什么 | skill 用它做什么 |
|---|---|---|
| `domain/` | 你已发表或已定稿的论文，最好是能编译的 LaTeX 源(每篇一个文件夹)，也可以是 PDF 或 docx | 领域知识、术语、记号、立场，以及结构、句式、定理与 Finding 写法、表和图的模仿对象 |
| `general/` | 你的基金本子、项目申请书、技术报告 | 学本子的句式与论证逻辑，锁定词从这里取 |
| `writing-samples/` | 最能代表你行文声音的中英文段落或全文 | `writing-deai.md` 的声音匹配，按它的句长、用词、段首和过渡改写 |
| `figures/` | 你满意的动机图、系统图、本子图的 PDF 与可编辑 PPT | 画新图时沿用其结构、功能色与实例组织 |
| `icons/` | 你的图标素材 PPT 或 SVG | 用 `paper-figure-pptx/scripts/extract_icon_library.py` 提取成可复用的矢量图标库 |
| `ppt/` | 你的学术报告与海报 PPT | 做整套汇报时仿其版式与讲法 |

## 建议

- `domain/` 里每篇论文写一行说明，记在本文件末尾的表里，例如刊物、年份、适合模仿什么。
- 双盲审稿期间的稿件只放在本机，不要提交到公开的分支。
- 参考图的索引与哈希放进 `paper-figure-pptx/assets/paper-references/manifest.json`，规则见 `paper-figure-pptx/references/paper-styles.md`。
